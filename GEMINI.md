# Project: Instagram account → small static website

You are running unattended. Never ask questions. Make decisions yourself, build the site, then print a short summary of what you built and any assumptions.

## Inputs

- `<username>_data/profile_data.json` — the only source of facts.
- `<username>_data/posts/web/*.webp` — images to use (max 640px on the long side; they are low-res thumbnails).
- `<username>_data/pfp.jpg` — profile picture (small; may be missing).

Do not use `posts/orig/`, `debug/`, or any `*.tmp` folder.

## Output

Write everything to `site/`. Copy the images you use into `site/assets/`. Plain HTML, CSS and a little vanilla JS. No frameworks, no build step, no CDN scripts. Google Fonts via a `<link>` is allowed, with sensible system fallbacks. Entry point: `site/index.html`. It must open correctly by double-clicking the file (relative paths only).

## Field meanings in profile_data.json

- `bio` — the owner's own words. Use it as written (fix line breaks only).
- `posts[].caption` — the owner's own words, but **empty for most posts. That is normal.** Never invent a caption for an empty one.
- `posts[].alt_text` — auto-generated by Instagram's image recognition ("May be an image of…", garbled OCR text). **Never show it as visible text.** At most, rewrite it into a short plain alt attribute after looking at the image.
- `posts[].date`, `stats_raw` — metadata. **Do not display likes or comments.** Dates may be used sparingly.
- `posts[].kind` — `reel` means the image is only a cover frame of a video. Link it to `url` and mark it as a reel with a small play marker drawn in CSS/SVG. Do not pretend it plays inline.
- `posts[].width/height` — use for aspect-ratio-aware layout.
- `followers` — may be shown once, quietly (e.g. "39K on Instagram"). Do not show following or post count.

## Content rules (strict)

- Use only facts present in the JSON. Do **not** invent: prices, product names, flavors, menus, reviews, testimonials, years in business, an address, an "About us" story, or statistics.
- Only use a caption verbatim if it is non-empty and not time-sensitive. **Ignore any caption about breaks, closures, sales, dates or "orders resume…"** — such notices go stale. Evergreen lines (a tagline, a description of the craft) may be used sparingly.
- If the bio or a caption contains a phone number marked for WhatsApp/orders, add an "Order on WhatsApp" link (`https://wa.me/<digits in international format>`; convert a leading 0 using the account's country, inferred from the bio's location). If there is none, link to the Instagram profile instead. Never invent a number.
- Payment methods, location and policies (refunds, etc.) from the bio belong in a plain "How to order" section, written plainly and honestly. Show policies as stated, small but readable. Do not soften or remove them.
- Link to the Instagram profile (`https://www.instagram.com/<handle>/`) in the header or footer.

## Image rules

- Images are at most 640px. **Never display one wider than ~500px** (or full-bleed). Large visual moments must come from typography, color and space, not stretched photos.
- Do not crop everything to uniform squares. Respect each image's aspect ratio and vary size and placement to create rhythm.
- Add `loading="lazy"`, explicit `width`/`height` attributes, and meaningful `alt` text.
- Before designing, actually look at the images. Derive the palette and mood from them.

## Design direction

Goal: it should look like a considered small-brand site designed by a person, not an AI template.

**Banned:**

- Purple, blue-purple or any gradients; gradient text; glow effects; glassmorphism
- A row of three equal feature cards; any generic "features" grid
- Borders or boxes around every section or image; heavy drop shadows
- Emoji as icons or decoration; stock-style icon sets
- Generic hero copy ("Welcome to…", "Elevate your…", "Get started")
- Testimonials, "Why choose us", newsletter signup, fake stats
- Centering everything

**Do:**

- Generous whitespace: large section padding, comfortable line height, narrow text columns (about 60 characters).
- A restrained palette taken from the photos: a warm or neutral background, near-black text, **one** accent color. State the hex codes in a CSS `:root` block.
- Type does the heavy lifting: one expressive serif or display face for headings plus one clean sans for body. Use a strong size contrast (very large headline, small quiet details).
- Asymmetric, editorial layout: staggered gallery with images at differing sizes and offsets, overlapping text and image where it helps, a masonry or collage feel rather than a grid of equals.
- Separate sections with spacing and type size, not lines and boxes.
- Subtle motion only: gentle fade/translate on scroll, hover states on links. Respect `prefers-reduced-motion`.
- Fully responsive. Check that it works at 375px wide and at 1440px wide. Keep the page fast.

## Suggested page structure

1. Header: name wordmark and a quiet link to Instagram / WhatsApp.
2. Opening: the account name large, with the bio's tagline. No filler copy.
3. Gallery: all usable posts, editorial layout, reels marked and linked.
4. How to order: location, payment, policies and the order link — from the bio only.
5. Footer: Instagram link, small handle, nothing else.
